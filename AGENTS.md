# AGENTS.md

Este arquivo é apenas um adaptador de entrada para agentes compatíveis com `AGENTS.md`.

A fonte de verdade das regras operacionais está em:

- `.ai/CONSTITUTION.md`
- `.ai/PRECEDENCE.md`
- `.ai/WORKFLOW.md`

Antes de editar qualquer livro, siga `START_HERE.md`.

## Regras essenciais

- Não trate este arquivo como canon narrativo.
- Não duplique aqui informações de personagens, mundo, timeline ou trama.
- Identifique o projeto em `projects/<slug>/` antes de trabalhar.
- Leia `PROJECT.md` e `STATUS.md` do projeto selecionado.
- Carregue apenas o contexto necessário à tarefa atual.
- Não invente informação ausente para resolver contradições.
- Mudanças de canon devem ser explícitas e versionadas.
- Atualize o `STATUS.md` do projeto quando o estado do trabalho mudar de forma relevante.
