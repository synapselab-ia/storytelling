# Canon

Fonte de verdade factual do projeto.

Aqui devem ficar fatos objetivos sobre mundo, personagens, locais, objetos, facções, relações, timeline, conhecimento e mudanças de estado.

Princípios:

- fatos importantes devem ter IDs estáveis quando estruturados;
- crença de personagem não é igual a verdade objetiva;
- manuscrito não altera canon implicitamente;
- contradições devem ser registradas e resolvidas deliberadamente.
