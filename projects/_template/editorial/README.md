# Project Editorial Rules

Regras de voz e estilo específicas deste livro.

Aqui devem ficar, conforme necessário:

- voz narrativa;
- POV e distância narrativa;
- regras de diálogo;
- ritmo e densidade descritiva;
- padrões proibidos;
- convenções de formatação;
- checklist editorial específico.

Regras realmente globais pertencem a `/editorial/`. Não copie conteúdo global para cá sem necessidade.
