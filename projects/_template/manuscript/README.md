# Manuscript

Prosa do livro em Markdown.

Estrutura recomendada:

```text
manuscript/
├── ch-001.md
├── ch-002.md
└── ...
```

O manuscrito é uma execução narrativa do planejamento, não uma fonte automática de canon.

Se a prosa introduzir um fato novo importante que deve se tornar verdadeiro para o projeto, registre-o deliberadamente na camada apropriada de canon.
