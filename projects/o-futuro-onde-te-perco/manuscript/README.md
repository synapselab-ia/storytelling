# Manuscript

A prosa definitiva do romance ficará neste diretório quando a pré-produção estiver suficientemente fechada.

## Regra atual

O projeto ainda está em pré-produção. Não criar capítulos definitivos aqui antes de resolver as prioridades registradas em `../STATUS.md` e `../story/DECISIONS_PENDING.md`, salvo se o usuário pedir explicitamente uma amostra exploratória.

Quando a escrita começar, usar arquivos como `ch-001.md`, `ch-002.md` etc. O manuscrito não é fonte primária de canon: contradições devem ser corrigidas no manuscrito ou formalmente promovidas a mudança de canon.
